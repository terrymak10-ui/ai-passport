# Eb 中音萨克斯 — 首个增量

完全离线的标准音与指法浏览器，基于 main 提交
`3d685a90bdb96dd8526d84edde1e63fec25b460e`。入口为 `main/sax_app.c`。
硬件 BSP 与默认分区不变，不启动无线协议栈。

## 操作与显示

- UP 选择前一个低音，DOWN 选择后一个高音；到端点不循环。
- OK 以当前 codec 音量（默认 80/100）持续播放正弦标准音，再按 OK 停止。首次请低声试听，喇叭远离耳朵。
  双击按一次操作处理。
- 长按 UP／DOWN 每次增加／减少 10 级音量，范围 40–100；每次先松开再长按。画面显示音量，开机恢复 80，播放中不可调节。
- 长按 OK 切换 WRITTEN（指法）与 CONCERT（实际音高），开机默认指法。
- 播放期间锁定选音、音量与模式切换，OK 仍可停止；显示 Stopping 时等待 10 ms 渐出和 PCM 排空，再选音或重新播放。停止响应时间待实测。
- 空闲 60 秒背光降至 5%，按键恢复亮度。
- 右上角显示电量，无法读取时显示 `--%`。

首版仅含 C 大调自然音，指法 C4 至 C6，共 15 音，并非完整半音指法表。
六个圆圈按左手 LH、右手 RH 分组，从左到右为食指、中指、无名指。
实心表示闭合，空心表示放开。Oct 为拇指八度键，C 为右手小指低音 C 键。
即使切换实际音高，指法图仍对应指法音。其他辅助键放开。
这份基础常规指法数据为应用编写，不包括替代指法或不同乐器的特殊机构；
需要萨克斯演奏者在设备上核对。

以 A4=440 Hz 为基准，实际 MIDI = 指法 MIDI - 9。
选择指法 C5 时播放实际 Eb4（311.12698 Hz），不会播放实际 C5。
使用 ASCII 升降号（Eb、F#）与科学音高八度编号。界面暂为英文，繁体中文字体待整合。

## 架构与测试

`main/sax_music.c` 独立于硬件，负责音符、频率、音名与连续相位振荡器。
正弦查找表放于 Flash，首尾渐变各 10 ms，不进行逐采样浮点三角运算。
独立音频任务负责阻塞 PCM 写入；按键回调只入队；UI 操作持 BSP LVGL 锁。
PCM 工作缓冲为 512 字节，无整段录音缓冲，也尚未持久化练习统计。
队列与任务贯穿应用生命周期，只有一个常驻页面。

`tests/test_sax_music.c` 验证移调示例、频率、音符边界与顺序、指法数据、
波形峰值／RMS、音量步进边界、不同分块下的相位连续性、渐变端点、播放／停止状态、超过一秒的连续串流与 A4 过零次数；已加入
`tools/validate.sh`。主机测试不能证明实际声学精度。

在 ESP-IDF 5.5.3 环境运行完整检查：

```sh
./tools/validate.sh
```

## 待验收与后续增量

实机检查开机、全部音符与键位、实音切换、边界导航、独立调音器测量的音高与音质、
重复播放、电量异常降级、空闲变暗及无看门狗/重启。
重复播放时记录最低 heap 与最大连续空闲块。本应用尚未进行实机测试。

待实现：收音质量诊断、YIN 调音器、cents、节拍器、音阶跟练、长音训练、
带日期练习统计、半音与替代指法、繁体字体及自动休眠。
不声称已达到 ±1 cent、50 ms 或 1 ms。默认分区没有 OTA 或文件系统。
未来每日统计在完全断电后需要手动日期或合适时钟来源。

构建产物必须通过共享合并映像与分区验证。刷写确切版本前需获得明确授权；
0x0 合并映像可能重置 NVS。本次已授权将源码提交并推送至功能分支；不合并、不发布 Release，也不刷写。

音频跟进：初版 45/100 设置在板级增益补偿前约为 -27.5 dB。测试修订使用基础音频示例的 80/100（约 -10 dB），PCM 幅度与首尾渐变保持不变，名义输出提高 17.5 dB，但不能据此证明喇叭实际发声。串口记录频率、格式设置和 PCM 完成情况。首版设备已观察到画面及播放完成状态，但未确认有声；修订版仍需实机复测。

第二次音频跟进：用户确认 80/100 版本的 C6 必须贴近耳边才听到。正弦 PCM 峰值由 5000 提至 16000（名义提高约 10.1 dB，保留 16-bit 余量），10 ms 渐变不变。音量可调至既有 API 上限 100。不在未经测量时改动板级增益假设或 codec 寄存器。试音时远离耳朵，有需要才逐级增加音量。实际响度、失真、低频响应及可用性仍待验证；写入成功不代表声学验收通过。

持续播放：OK 切换播放／停止，显式区分 STOPPED／PLAYING／STOPPING。音频任务在 256 个采样的区块之间检查带播放代号的停止通知，停止不依赖启动队列。任务尚未开始时收到的停止请求仍保留，旧代号不会中断下一次播放。相位与起音状态跨区块保持，不循环一秒音频或重复渐变。先停播再选音、调音量或切换模式。播放中不自动调暗背光。持续播放的耗电、温升与停止延迟仍待实机验收。
