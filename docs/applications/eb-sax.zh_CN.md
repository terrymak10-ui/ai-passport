# Eb 中音萨克斯练习应用

完全离线的 ESP32-C3／8 MB Flash／无 PSRAM 应用，基于 main 提交
`3d685a90bdb96dd8526d84edde1e63fec25b460e`。入口 `main/sax_app.c`。
BSP、GPIO 与默认分区不变，不启动无线协议栈。

## 音域与操作

现支持**指法 Bb3–F#6 连续 33 个半音**（MIDI 58–90），开机选中指法 C5。
A4=440 Hz；实际 MIDI = 指法 MIDI - 9。实际音域 Db3–A5，约 138.59–880 Hz。
指法 C5 播放实际 Eb4，311.12698 Hz。默认显示 `指法音高`；切换 `實際音高` 不改变指法或播放频率。

- 短按 UP／DOWN：向低／高半音选择，到端点不循环。
- 短按 OK：持续播放／停止；双击按一次操作处理。
- 停播时长按 OK：切换指法／实际音高。
- 长按 UP／DOWN：每次增减 10 级音量，范围 40–100，每次先松开。
  开机默认音量现为 **90**（之前 80），不持久保存。
- 播放期间锁定音符、音量和模式；OK 仍可停止。等待 STOPPING 结束才重新播放或更改设置。
- 停播后空闲 60 秒背光变暗，按键恢复亮度。
- 右上角显示电量，无法读取时为 `--%`。界面与手指提示使用专用繁体中文字集。

降号用 b，升号用 #。大音名下方显示等音别名，例如 Db4／C#4、F#4／Gb4。
八度采用科学音高编号。

## 指法图

原创新绘的 240 x 185 简化示意图取代辅助键格子。六个主圆圈纵向排列：
上三键是左手食指／中指／无名指，下三键是右手食指／中指／无名指。
键旁直接标注繁体中文手指名称。**黄色实心键及黄色手指名表示按下，灰色空心键表示放开。**
下方两行列出每只手需要按下的手指，完全放开时显示 `全部放開`。
例如 C5 只按左中指；C4 按左三指与右三指及右小指。掌侧、侧键与主键分别提示。

图中显示演奏者操作的触键，而非全部机械联动音孔；它是正面示意图，
背面的八度键刻意移至拇指提示旁。辅助键按操作手分组：

| 标签／位置 | 含义／操作手 |
| --- | --- |
| T，`左拇指` 旁 | 左拇指八度键 |
| G#／C#／B／Bb，左下 | 左小指 G#／低音 C#／B／Bb |
| C／Eb，右下 | 右小指低音 C／Eb |
| Bb，右上 | 右食指侧 Bb，并非左手 bis Bb |
| D／Eb／F，左上 | 左手掌键 |
| E，右上 | 右食指上侧 E 键 |
| F#，`右中指側` 旁 | 右中指专用高音 F# 键 |

每音采用一种常用基础指法：Bb4／Bb5 采用侧 Bb，F#4／F#5 采用右手中指，
D6 及以上采用掌键。F#6 使用专用高音 F# 键，并显示 **需高F#鍵**。
没有该键的乐器需要适合自身型号的替代指法，本版不把它当作通用方案。
其余替代指法、front、bis 与超吹指法暂未收录。

按键组合核对参考（不复制原图）：

- [Yamaha 原声萨克斯指法指南](https://www.yamaha.com/en/musical_instrument_guide/saxophone/play/play002.html)。
- Timothy Reichard 的 Woodwind Fingering Guide：[第一八度](https://www.wfg.woodwind.org/sax/sax_bas_1.html)、[第二八度](https://www.wfg.woodwind.org/sax/sax_bas_2.html)、[按键说明](https://www.wfg.woodwind.org/sax/sax_fing.html)、[高音 F# 方案](https://www.wfg.woodwind.org/sax/sax_alt_4.html)。
- [NoteAtlas 高音 F# 基础组合](https://www.noteatlas.org/instruments/alto-sax/notes/high-f-sharp/)。

这份表不是对用户乐器的实测保证，仍需演奏者／教师在设备上核对全部 33 音。

## 低音播放改善

此前实机观察：C6 有声，但音量 100 时低音仍很弱。本版改变音色，不尝试无限放大：

- 实际频率不高于 311.13 Hz（指法 C5 及以下）时，混合基频及第二、三、四泛音，
  权重 `1 : 0.65 : 0.45 : 0.30`，查找表归一化至 PCM 峰值 **20000**。
- 实际 311.13–440 Hz 逐步过渡到纯正弦；实际 A4（指法 F#5）及以上仍用峰值 **16000** 的正弦。
- 泛音为正确实际基频的整数倍，不以高八度代替低音。该音色是合成参考音，并非萨克斯录音或仿真。
- 开机音量由 80 改成 90；依赖的默认音量曲线在板级增益补偿前名义提高 5 dB，实际声压未测。
- 表内插值与音色过渡是凸组合，生成 PCM 不超出 +/-20000；没有硬削波，保留首尾 10 ms 渐变。

两张常量表保存在 Flash，新增表 514 字节。每采样只作整数插值，不作浮点三角运算。
512 字节 PCM 缓冲、24 KiB LVGL 池与 LCD DMA 配置不变。
整个键位图使用一个自绘 LVGL 对象，不再使用 19 个独立键控件。
`main/sax_diagram.c` 管理位置与手指对应，`main/sax_ui.c` 管理绘制和文字；
控制器与音频任务仍在 `sax_app.c`。

用户刷写前一个 33 音／泛音版本后报告声音清楚很多
（SHA-256 `e9aac0bf7143ad128a1b590dd1aee09568bfce8518a932b348f6bfe36cb1d572`）。
这属于主观反馈，各频率与聆听距离仍未量测。数码峰值限制不能证明模拟电路余量、
喇叭响应、正常距离响度、耗电或温升。先远离耳朵试音，再逐级调整。
不能把音量 100 或 PCM 写入成功当作声学验收通过。

## 播放架构与验证

`main/sax_music.c` 独立于硬件，负责音符、音名、频率、音量、音色、包络和播放状态。
独立任务拥有 PCM；按键回调只入队；UI 使用 BSP LVGL 锁。
STOPPED／PLAYING／STOPPING 与带代号的停止通知避免旧请求取消新播放。
相位跨区块连续，起音计数饱和后不再增长；停止时渐出 10 ms，再写静音排空并确认。
实际停止延迟待测。

`tests/test_sax_music.c` 验证 33 音连续 MIDI、移调、跨八度主键／辅键关系、
低音与掌键及 HF# 组合、等音名、半音频率比、音量边界、连续播放、渐变及峰值／RMS。
频谱测试核对低音基频和各泛音比例，以及实际 A4 保持纯音。
主机测试不能验证真正的喇叭声音或指法操作感。

```sh
./tools/validate.sh
```

## 字体与主机预览

`assets/fonts/sax_tc_14.c` 是 14 px／4 bpp、未压缩、131 字符的固定界面子集，
行高 17 px，源自固定版本的 OFL 字体。见[资源与重现命令](../../assets/README.zh_CN.md#sax-ui-font)。
正文控件和图中提示明确选择此字体；大音名和辅助 ASCII 标记使用 Montserrat。
不支持任意中文输入。默认配置明确启用 UTF-8 与缺字占位。

可选的真实 LVGL 主机渲染使用同一 UI／字体、24 KiB LVGL 池、19.2 KiB RGB565
分块缓冲与 BSP 圆角判断。ESP-IDF 下载固定 Managed Components 后运行
（需要 CMake／Ninja／C 编译器）：

```sh
cmake -S tests/sax_ui_host -B /tmp/sax-ui-host -G Ninja
cmake --build /tmp/sax-ui-host -j3
/tmp/sax-ui-host/preview assets/fonts/sax_tc_14.txt /tmp/sax-preview
```

测试包含字符覆盖及已知缺字反例、实际控件字体、图形位置、33 音的左右手文字宽度、
66 次画面渲染及 100 次播放状态更新，输出 C4／C5／F#6 PPM 预览。
启用断言的主机测试在 24 KiB 池中剩余 7032 字节，最大连续块 6632 字节；
这不是板子的系统 heap。静态检查另测几何边界、完整主键／辅键映射及 UTF-8 全有或全空复制。
[PNG 预览](../../assets/README.zh_CN.md#sax-ui-previews) 是模拟画面，不是设备实拍。

## 实机验收与未完成项

当前版本：**未进行实机测试**。需验证全部 33 音及辅助键、文字和裁切、HF# 提示，
正常距离的 Bb3／B3／C4／B4／C5／C6 可听度，独立调音器测得的音高、音色和失真，
持续播放／停止／重启，电量异常、闲置变暗、最低 heap／最大连续空闲块、看门狗，
以及长时间播放的耗电和温升。若低音仍难听到，应检查实际喇叭／功放路径，不能假设继续加增益即可。

前一个 33 音版本：用户确认刷写成功、音量清楚很多；新的键位图／繁体中文界面尚未实机验收。

待实现：收音／YIN／cents、节拍器、音阶跟练、长音训练、日期统计、替代及超吹指法、
自动休眠。不声称 +/-1 cent、50 ms 或 1 ms 已达成。
默认无 OTA／文件系统；完全断电后的日期统计需合适时钟或手动日期。
仅按授权发布到功能分支／草稿 PR，不自动合并、发布 Release 或刷写。
